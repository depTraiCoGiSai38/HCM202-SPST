# IMAGE RESEARCH PROTOCOL

Research each stage separately.

For every candidate:

## A — DOCUMENT IDENTITY

Establish:

- institution / holding archive;
- item record;
- collection / identifier where available;
- creator where the source states one.

A search-result page is NOT evidence.

Open the original item record.

---

## B — SUBJECT / EVENT / DATE / PLACE

Maintain these separately:

### identity
Who does the source say is in the image?

### event/date
What event/date does the source itself state?

### location
What location does the source itself state?

Do not infer one axis from another.

If unknown:

state that it is unknown.

---

## C — USAGE CONDITIONS

Open the actual usage / rights page of the holder.

Record the relevant wording.

Do not convert:

“no reuse information found”

into:

“reuse prohibited”.

Those are different states.

If permission is unclear:

`NEED VERIFICATION`

and do not ship the image.
