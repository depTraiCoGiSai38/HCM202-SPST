WHAT MUST CHANGE

1. SOURCE LABEL — public textbook citation becomes exactly
   `Giáo trình Tư tưởng Hồ Chí Minh - 2019`, e.g. `..., tr. 29` or `..., tr. 29–31`.
   Do not use `C2 PDF p.3` as the visible citation.

2. PAGE LOCATORS — update every textbook locator to the correct printed 2019 page.
   Do not mechanically add/subtract a fixed offset. Verify each claim against the
   actual 2019 page where it appears. A claim spanning multiple pages should use
   the smallest accurate page range.

3. STAGE HEADINGS — audit the broad boundaries against the exact 2019 source and
   prefer the exact 2019 wording. Do not silently keep later-edition wording.

4. CLAIM CONTENT — do NOT rewrite claim content unless comparison with the 2019
   source shows a real wording/content difference. Preserve the existing UX redesign,
   interactions, narrative architecture, image system, motion system and source
   verification infrastructure.

5. ORIGINAL / SECONDARY SOURCES — do NOT replace valid references to
   Hồ Chí Minh: Toàn tập, Văn kiện Đảng: Toàn tập, archival image sources, BnF /
   museum sources, or other original-document evidence with the textbook label.
   Do not collapse textbook source and original document source into one citation.

6. SOURCE DATA MODEL — keep internal distinction between source file, PDF page and
   printed textbook page, but the public UI must use the printed textbook page.
   Do not invent the structure if the existing data model already solves it cleanly.
   Adapt minimally.

7. SOURCE-OF-TRUTH UPDATE — active project documentation must state the primary
   academic content source. `C2-02.pdf` becomes LEGACY / COMPARISON REFERENCE and
   must no longer control public locators. Do not delete it automatically.

8. HASH / INTEGRITY — compute SHA-256 for the new 2019 PDF, record it, do not
   silently overwrite old hash history, mark the old C2 file as superseded for
   academic locator purposes, and follow the AGENTS re-audit protocol.

9. SOURCE VERIFICATION LOG — update the Source Verification Map. Do not mark
   VERIFIED merely because an automated script found matching words. If not
   manually verified: NEED HUMAN VERIFICATION.

10. UI — update all user-visible source text. Keep it compact; do not let the
    longer source label dominate the UX. Source detail can live in the existing
    source drawer / verification view.

11. TESTS — update tests that depend on source label, page numbers, stage
    boundaries, expected headings, locator text, PDF-page counts. Do not weaken
    tests. Add tests preventing old public citation labels from returning.

12. REPOSITORY-WIDE STALE-REFERENCE CHECK — classify every remaining occurrence of
    C2-02 / C2 PDF / 2021 as LEGITIMATE HISTORICAL / MIGRATION RECORD or
    STALE ACTIVE REFERENCE. There must be zero stale active references before
    finishing. Do not erase Prompt Logs or historical reports.

13. DO NOT REWRITE HISTORY — Prompt Logs and previous audit reports must preserve
