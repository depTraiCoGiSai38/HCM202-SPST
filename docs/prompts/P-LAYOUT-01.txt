# 15. HORIZONTAL BALANCE RULE

At desktop widths >= 1200px:

no major stage BODY state should unintentionally occupy only the left
~45–50% of the usable canvas while the entire right side remains structurally
empty.

Valid exceptions:

1. content is deliberately centered;
2. whitespace is clearly intentional and balanced;
3. a full-width visual / timeline / transition provides composition.

Invalid:
normal left column + unused blank right half
